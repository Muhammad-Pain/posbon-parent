# Посбон — барномаи волидайн (сохт дар абр, бе компютер)

Ин лоиҳа APK-ро дар **GitHub** месозад — ба ту компютер лозим нест, ҳама чиз аз телефон.

## Дар репозиторий ҳамагӣ 3 файл лозим аст:
1. `pubspec.yaml`
2. `lib/main.dart`
3. `.github/workflows/build.yml`

## Қадамҳо (аз телефон):
1. Дар **github.com** аккаунт соз (ройгон).
2. Репозиторийи нав соз: ном `posbon-parent`, **Public**, «Add a README file»-ро интихоб кун.
3. Ҳар 3 файлро илова кун: «Add file» → «Create new file» → ном (масалан `lib/main.dart`) нависед → матнро гузоред → «Commit».
4. Варақаи **Actions** — сохт худкор сар мешавад (~5–10 дақиқа).
5. Баъди сабз шудан: ба он сохт даро → поён **Artifacts** → `posbon-parent-apk`-ро боргирӣ кун.
6. Файли APK-ро дар телефон кушо ва насб кун (иҷозати «манбаъҳои номаълум»-ро дода).
